# Indicadores de Calidad - Sistema de Gestión de Inventarios

### Mantenibilidad
- Densidad de defectos: <5 por 1000 líneas de código
- Complejidad ciclomática: <10 por método
- Documentación: ≥70% de clases documentadas

## Herramientas de Monitoreo
- **JUnit**: Cobertura de pruebas
- **JMeter**: Pruebas de rendimiento
- **Playwright**: Pruebas de usabilidad
- **Prometheus/Grafana**: Monitoreo en tiempo real

## Criterios de Aceptación
- Cobertura ≥80%
- Tiempo de respuesta dentro de límites
- Tasa de errores <1%
- Usabilidad ≥4/5
- Sin vulnerabilidades críticas

## Métricas de Calidad

### Cobertura de Pruebas
Porcentaje de código cubierto por pruebas unitarias, integración y aceptación (≥80% recomendado).

### Tasa de Errores
Porcentaje de transacciones fallidas (<1%).

### Usabilidad
Puntuación en pruebas automatizadas con Playwright (≥4/5 en flujos de usuario).

### Disponibilidad
Tiempo de actividad del sistema (≥99.5%).

### Seguridad
Ausencia de vulnerabilidades críticas en pruebas de penetración.
