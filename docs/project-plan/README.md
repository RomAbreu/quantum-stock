# Plan de Proyecto - Sistema de Gestión de Inventarios

## Alcance
Desarrollo de Sistema de Gestión de Inventarios aplicando conocimientos de QAS.

### Funcionalidades Incluidas
- **Gestión de Productos**: CRUD completo con búsqueda y filtrado  
- **Control de Stock**: Actualización, alertas de stock mínimo, historial de movimientos  
- **Integración**: API con autenticación JWT para sistemas externos  
- **Interfaz**: Dashboard intuitivo y navegación amigable  
- **Roles**: Administrador (acceso total), Empleado (básico), Invitado (solo lectura)  
- **QAS**: Pruebas completas, CI/CD, monitoreo y documentación  

## Objetivos
1. Crear sistema eficiente y amigable para PYMEs  
2. Aplicar rigurosamente metodologías QAS  
3. Demostrar colaboración profesional vía GitHub  
4. Cumplir estándares de usabilidad y rendimiento  
5. Fomentar aprendizaje práctico con retrospectiva  

## Entregables

### Sistema Funcional
- Código completo en repositorio GitHub público  
- Todas las funcionalidades implementadas y probadas  

### Documentación
- **Requisitos**: Funcionales y no funcionales  
- **Técnica**: Arquitectura, instalación, mantenimiento  
- **Pruebas**: Casos de prueba, resultados y defectos  
- **Calidad**: Métricas y gestión de riesgos  

### Componentes Técnicos
- **CI/CD**: Pipeline con GitHub Actions  
- **Contenedorización**: Docker para deployment  
- **Migraciones**: Flyway para base de datos  
- **Monitoreo**: OpenTelemetry para observabilidad
