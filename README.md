# Quantum Stock  

**Quantum Stock** es una aplicación full-stack para la gestión de inventario, con funcionalidades como:  
- CRUD de productos  
- Monitoreo de stock en tiempo real  
- Búsqueda y filtrado  
- Autenticación de usuarios
